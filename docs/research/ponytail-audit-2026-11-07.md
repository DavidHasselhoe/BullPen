# Ponytail audit, 2026-11-07 (performance + cleanup)

Whole-repo scan of `C:\bullpen` at `bc12c672` (preview). Read-only: nothing was changed. Previous passes: ponytail audit 2026-09-05 (3 deps removed, all fixed) and code review + perf 2026-09-13. Their fixes held, with one small regression (a re-added local `sleep`, Q9).

**Method.** An import-graph script over all 1,375 TS/TSX files (transitive: a file whose only importers are dead files counts as dead). An API-route reference scan over 202 `route.ts`. Per-package import counts. A per-call `useQuery` parse to check `staleTime`. Greps for TwelveData, Supabase `.in()`/`.range()` and tier patterns. Reads of `middleware.ts`, `app/layout.tsx` and the Next 16 docs in `node_modules/next/dist/docs`. `eslint .` ran clean: 0 errors, 0 warnings. No `npm run build` (shared dev server), so client bundle sizes are inferred from imports, not measured.

**Clean areas (no finding):** TanStack Query (global `staleTime: 60s` in `app/providers.tsx`. Of 152 query calls, the only one with no explicit `staleTime` is `VerifyEmailNotice`, which polls on purpose. The other two the scan flagged reuse the shared `CURRENT_PICK_QUERY` options object). Heavy client libs are already lazy: jspdf via `import()`, `BullpenChat`/react-markdown via `lazy()`, `AdvancedChartModal`/lightweight-charts via `dynamic()`, the command palette and stock-page cards. `getStockQuote` is never called in a TwelveData loop. The quote, Why Today and sector-row fetches are batched or open on demand. `getDisplayNames` is memoised, so the metadata and page calls don't double-query.

Tags: `delete` dead code, `yagni` flexibility nobody uses, `shrink` same logic in fewer lines, `stdlib`/`native` replace with a platform feature, `perf` measurable runtime cost.

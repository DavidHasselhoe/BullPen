# Illustrations

App illustrations used by `components/ui/EmptyState.tsx` (empty states, 404, etc.).

## Files

- `bull-shrug.png` — the BullPen mascot (shrugging bull) used as the default
  empty-state illustration.

## Guidelines

- **Transparent background**, black line art. The `EmptyState` component applies
  `dark:invert`, so black lines flip to white in dark mode — a transparent
  background keeps that clean (no dark box behind the art).
- Square-ish aspect ratio, ~512–1024px, PNG (or SVG).
